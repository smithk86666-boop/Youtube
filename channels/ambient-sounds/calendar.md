# Still Weather: first 90 days

Runs in parallel with `sleep-stories` as one arm of the format test. Same dates and cadence so results are comparable.

| Weeks | Goal | Output |
|---|---|---|
| 1-2 | Validate and set up | Query sampling, name and handle, Google account + channel, recording method chosen, 5 distinct audio sources secured with proof |
| 3 | Pilot | Produce 001; check Content ID, loudness, upload and processing of an 8-hour file |
| 4-5 | Launch | Publish 001-004 (2 per week) |
| 6-8 | Learn | Publish 005-010. Length test (3 vs 8 hours), mid-roll test |
| 9 | Read | 28-day results vs `sleep-stories` per the decision rule in `docs/experiments/2026-q4-format-test.md` |
| 10-13 | Act | Scale, pivot, or stop this arm based on the read |
