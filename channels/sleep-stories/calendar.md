# Quiet Hours: first 90 days

Cadence assumption: 2 long videos per week once production is running. Adjust after the first review. The Feb 2027 threshold increase (reported, unverified) makes early watch hours valuable, but quality and variation come before speed.

| Weeks | Goal | Output |
|---|---|---|
| 1-2 | Validate and set up | Niche sampling done, name/handle chosen, Google account + channel created with 2-Step Verification, AdSense linked, voice and music providers chosen with licenses saved |
| 3 | Pilot | Scripts 001-003 written; produce 001; test pipeline on one video, check Content ID, disclosure decision, loudness |
| 4-5 | Launch | Publish 001-004 (2 per week). Add banner, about text, playlists |
| 6-8 | Learn | Publish 005-010. Run length test (60 vs 150), mid-roll test. Review retention at week 8 |
| 9-10 | Decide | Keep sub-niche, adjust, or pivot per `strategy.md` validation. Update backlog and `CLAUDE.md` with what worked |
| 11-13 | Scale cautiously | Publish 011-016 with varied topics. Apply for API audit if manual process is stable. Reassess YPP progress against the thresholds in force |

## Weekly routine
- Mon: pick topics from backlog, write scripts
- Tue-Wed: produce
- Thu: compliance gate, schedule
- Fri: review last week's analytics and record `results:`
